主页 现有

描述: 系统主页和概览

数据集 现有

路由: dataset

组件: DatasetPage.jsx

描述: 数据集管理和上传

训练任务 现有

路由: tasks

组件: TasksPage.jsx

描述: 训练任务管理和监控

模型 现有

路由: models

组件: ModelsPage.jsx

描述: 模型管理和测试

🆕 新增路由

服务管理 新增

路由: services

组件: ServicesPage.jsx

描述: 外部服务状态监控和管理

功能: TCP服务、Triton服务、Label Studio服务状态检查

TCP图像处理服务 新增

路由: services/tcp-image-processor

组件: TcpImageProcessorPage.jsx

描述: TCP图像处理服务专用页面

功能: 图像上传处理、历史记录、统计信息、服务状态监控

🔗 后端API端点

IImageProcessor API 新增

基础路径: /IImageProcessor

端点:

  • GET /info - 获取模块信息
  • GET /testConnection - 测试TCP连接
  • POST /processImage - 处理上传图像
  • POST /processImageFromDataset - 处理数据集图像
  • GET /getProcessingHistory - 获取处理历史
  • GET /getProcessingStatistics - 获取统计信息
  • GET /getServiceStatus - 获取服务状态
  • POST /deleteProcessingRecord - 删除处理记录
  • POST /clearProcessingHistory - 清空历史记录

🎯 测试步骤

  1. 启动后端服务: 运行 python backend/main.py
  2. 启动前端服务: 运行 npm run dev
  3. 访问服务页面: 点击导航栏中的"服务"按钮
  4. 测试TCP服务: 进入TCP图像处理服务页面
  5. 检查状态: 验证服务状态显示是否正常
  6. 测试功能: 上传图像进行处理（需要C++服务运行）

⚠️ 注意事项

  • TCP图像处理功能需要C++服务在 10.10.21.224:16000 运行
  • 可以通过环境变量修改TCP服务地址和端口
  • 所有处理记录会保存在用户主目录的 .yolo_training_visualization_platform/image_processing_history
  • 支持的图像格式：JPG, PNG, BMP, TIFF, WEBP
  • 最大文件大小限制：10MB
