# Frontend Design Skill

这个 skill 专门用于创建独特、生产级的前端界面，具有高质量的设计水准。避免通用的 AI 生成美学，创造真正令人难忘的界面设计。

## 核心特性

### 🎨 设计思维
- **大胆的美学方向**：选择极端的设计风格（极简主义、极繁主义、复古未来主义、有机自然、奢华精致等）
- **独特性**：创造令人难忘的界面，避免千篇一律的设计
- **意图性**：每个设计选择都有明确的目的和方向

### 🛠️ 技术实现
- 生产级功能代码
- 视觉冲击力和记忆点
- 统一的美学观点
- 精致的细节处理

## 设计指南

### 字体选择
- 避免通用字体（Arial、Inter、Roboto）
- 选择独特、有趣的字体组合
- 将独特的展示字体与精致的正文字体配对

### 色彩与主题
- 坚持统一的美学风格
- 使用 CSS 变量保持一致性
- 主导色配以鲜明的强调色

### 动画与交互
- 优先使用 CSS 动画
- 专注于高影响力的时刻
- 使用滚动触发和悬停效果创造惊喜

### 空间构图
- 意想不到的布局
- 不对称性、重叠、对角线流动
- 破网格元素
- 慷慨的留白或受控的密度

### 背景与视觉细节
- 创造氛围和深度
- 添加符合整体美学的效果和纹理
- 渐变网格、噪点纹理、几何图案、分层透明度

## 设计原则

1. **避免通用美学**: 拒绝千篇一律的 AI 生成设计
2. **大胆决策**: 选择明确的设计方向并坚持执行
3. **注重细节**: 每个像素都要精心设计
4. **情境相关**: 设计要符合具体的使用场景和受众
5. **技术匹配**: 实现复杂度要与美学愿景相匹配
