# Algorithmic Art Skill

这个 skill 专门用于使用 p5.js 创建算法艺术，具有种子随机性和交互式参数探索功能。

## 核心功能

### 🎨 算法哲学创建
- 建立计算美学运动的基础
- 定义指导视觉输出的规则
- 确定可控制和修改的参数
- 设定创造连贯性的边界

### 🛠️ 交互式艺术生成
- 使用 p5.js 实现生成算法
- 实时参数控制和视觉反馈
- 种子随机性确保可重现性
- 高质量艺术作品导出

### 📁 输出文件
- **philosophy.md** - 概念基础文档
- **viewer.html** - 交互式网页界面
- **artwork.js** - 生成算法实现

## 创作原则

1. **原创性**: 创建独特算法，不复制现有艺术家
2. **交互性**: 允许用户探索参数空间
3. **可重现性**: 使用种子随机性获得一致结果
4. **性能**: 优化实时交互体验
