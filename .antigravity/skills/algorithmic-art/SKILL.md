Algorithmic philosophies are computational aesthetic movements that are then expressed through code. Output .md files (philosophy), .html files (interactive viewer), and .js files (generative algorithms).

This happens in two steps:
1. Algorithmic Philosophy Creation (.md file)
2. Express by creating p5.js generative art (.html + .js files)

First, undertake this task:

## ALGORITHMIC PHILOSOPHY CREATION

### THE CRITICAL UNDERSTANDING

Algorithmic art is not about randomness - it's about **controlled chaos**. Every great algorithmic art piece has a philosophical foundation that guides the computational aesthetic.

### HOW TO GENERATE AN ALGORITHMIC PHILOSOPHY

1. **Choose a Core Concept**: Select a fundamental natural or mathematical phenomenon
2. **Define Aesthetic Principles**: Establish rules that govern visual output
3. **Identify Parameters**: Determine what aspects can be controlled/modified
4. **Set Constraints**: Define boundaries that create coherence

### PHILOSOPHY EXAMPLES

- **Flow Field Philosophy**: "Visualizing invisible forces through particle trajectories"
- **Emergent Complexity Philosophy**: "Simple rules creating complex, organic behaviors"
- **Geometric Harmony Philosophy**: "Mathematical relationships expressed as visual rhythm"
- **Chaotic Order Philosophy**: "Finding patterns within randomness through computational lenses"

### ESSENTIAL PRINCIPLES

- **Originality**: Create unique algorithms, don't replicate existing artists
- **Interactivity**: Allow users to explore parameter space
- **Reproducibility**: Use seeded randomness for consistent results
- **Performance**: Optimize for real-time interaction

## DEDUCING THE CONCEPTUAL SEED

From the user's request, extract:
- **Visual Theme**: What aesthetic are they seeking?
- **Interaction Level**: How much user control is needed?
- **Complexity**: Simple elegance or intricate detail?
- **Technical Constraints**: Performance, browser compatibility, etc.
